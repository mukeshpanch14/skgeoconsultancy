# SK Geo Consultancy landing page

Static one-page site. Open `index.html` in a browser; there is no build step.

- `index.html`: the whole page (inline styles; Google Fonts Barlow / Barlow Condensed)
- `images/`: logo (cropped from the business card) and 6 free Unsplash photos (Unsplash License, commercial use OK, no attribution required)
